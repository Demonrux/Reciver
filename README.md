# Лабораторная работа №3 — «Ресивер»

WinForms-приложение на C#: расчёт массы газа в ресивере
по уравнению состояния идеального газа.

## Формула

m = (p + 1) · 98000 · V / (R · (T + 273))

- R = 287 Дж/(кг·К) — газовая постоянная воздуха
- V = 1 м³ — объём ресивера
- p — избыточное давление, ати
- T — температура, °C
  
## Что умеет
- Ввод давления и температуры с фильтром (только цифры, одна запятая)
- Защита от вставки нечисловых символов
- Enter в любом поле = вычисление
- Стилизованный интерфейс (Segoe UI, карточки, акцентная кнопка)
  
## Запуск
Открыть `Reciver.sln` в Visual Studio → F5.
