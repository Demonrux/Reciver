0Что мы делали

ЛР №1 — это первая программа на C#. Мы создали консольное приложение: без кнопок и окон, только текст в чёрном окне и ввод с клавиатуры.

Главная цель — понять, как устроена программа на C#, и научиться вводить числа, считать и красиво выводить результат.

1Структура проекта

Когда создаёшь «Console Application», Visual Studio делает папку с кучей файлов. Не все из них ты будешь редактировать — большинство создаётся автоматом.

Файл / папкаЧто это
Имя.sln«решение» — объединяет один или несколько проектов
Имя.csprojфайл проекта — список файлов и настроек
Program.csглавный файл с кодом — его ты и редактируешь
Properties/AssemblyInfo.csинформация о сборке (версия, автор и т.п.)

✓

Из всего этого вручную ты правишь только Program.cs. Остальное — служебное.

2using, namespace, class — каркас любой программы

Любая программа на C# выглядит примерно так:

csharpusing System;                     // 1. Подключаем «библиотеку»

namespace lab1_1                   // 2. Своё «имя проекта»
{
    class Program                 // 3. Класс — контейнер для кода
    {
        static void Main()          // 4. Точка входа — с неё всё начинается
        {
            Console.WriteLine("Привет!");
        }
    }
}

Что такое using

using System; — это «разрешение пользоваться всем, что лежит в библиотеке System». Без него пришлось бы писать System.Console.WriteLine вместо просто Console.WriteLine.

Что такое namespace

Это «фамилия» твоего проекта. Представь, что у двух программистов есть класс User — при объединении их проектов возникнет конфликт. Namespace решает проблему: у одного Shop.User, у другого Blog.User.

Что такое class

C# — объектно-ориентированный язык. Вся программа — это набор классов. Минимум один класс нужен, чтобы было куда положить Main.

Что такое Main

Это точка входа — первая функция, которую вызывает .NET при запуске .exe. Без неё программа не запустится.

Main — как дверь

Программа — как дом. Main — единственная входная дверь. Что бы ты ни написал ещё, .NET заходит только через неё.

static void

static — метод принадлежит классу (не объекту). void — ничего не возвращает. Для Main это обязательно.

3Console — ввод и вывод

Класс Console — твой единственный «интерфейс» с пользователем в консольном приложении. У него всего 4 метода, которые ты будешь использовать на 99%:

МетодЧто делает
Console.WriteLine("текст")выводит текст и переходит на новую строку
Console.Write("текст")выводит текст без перехода (следующий вывод — сразу за ним)
Console.ReadLine()читает строку, введённую пользователем, до нажатия Enter. Возвращает string
Console.Read()читает один символ (вернёт число — код символа). Используется в конце, чтобы окно «не закрывалось сразу»

Зачем Read() в конце

Если не поставить паузу, программа отработает и консольное окно мгновенно закроется — ты не увидишь результат. Console.ReadLine() или Console.Read() в конце = «подожди, пока пользователь нажмёт Enter».

Пример диалога

csharpConsole.Write("Как вас зовут? ");
string name = Console.ReadLine();   // прочитали строку
Console.WriteLine("Привет, " + name);

4Сборка и запуск — F6 и F5

Программа на C# — это текст. Чтобы компьютер её выполнил, нужно сначала собрать (скомпилировать) в .exe, а потом запустить.

ДействиеКлавишиЧто происходит
СобратьF6компилируется, в окне «Ошибки» видно результат
ЗапуститьF5сборка + запуск с отладчиком (можно ставить точки останова)
Запустить без отладкиCtrl+F5сборка + запуск быстрее, но без отладчика
⚠

Часто спрашивают: «Чем отличается F5 от Ctrl+F5?» — «F5 запускает с отладчиком (можно останавливать на точках), Ctrl+F5 — просто запуск, для быстрой проверки».

Где найти готовый .exe

После сборки файл лежит в bin/Debug/Имя.exe. Его можно запускать двойным кликом — без Visual Studio.

5Типы данных — что важно знать

В C# у каждой переменной есть тип — от него зависит, какие значения можно хранить и сколько места занимать.

ТипЧто хранитПример
intцелое число (32 бита)int age = 20;
longбольшое целое (64 бита)long big = 9_000_000_000;
floatдробное, 7 знаковfloat x = 3.14f;
doubleдробное, 15–16 знаковdouble y = 9.81;
charодин символchar c = 'A';
stringстрока текстаstring s = "Привет";
boolистина/ложьbool ok = true;
💡

float vs double: double точнее. В обычных расчётах используют double. У float в конце числа пишут f (3.14f), иначе компилятор подумает, что это double.

6Convert — превращение типов

Проблема: Console.ReadLine() всегда возвращает string. Даже если пользователь ввёл 42, это строка «42», а не число. Складывать строки нельзя — получишь «42» + «8» = «428».

Решение: превратить строку в число через класс Convert.

csharpstring s = Console.ReadLine();     // "42" (строка)
int    i = Convert.ToInt32(s);      // 42 (целое)
double d = Convert.ToDouble(s);     // 42.0
float  f = Convert.ToSingle(s);     // 42.0f

Часто пишут в одну строку:

csharpint x = Convert.ToInt32(Console.ReadLine());
⚠

Если пользователь введёт не число (например, «abc»), Convert.ToInt32 упадёт с ошибкой. На ЛР №1 это не страшно — препод знает. На ЛР №4 уже учимся ловить такие ошибки через try/catch.

Convert vs Parse

Можно и так: int.Parse("42") или double.Parse("3.14"). Оба дают одинаковый результат. Разница — детали, для лабы неважны.

7Строковые методы — PadLeft и другие

В задачах на таблицу температур (Цельсий → Фаренгейт) нужно выровнять столбцы. Для этого в C# есть методы класса string:

МетодЧто делает
s.Lengthдлина строки (сколько символов)
s.IndexOf("x")номер символа «x» в строке (с нуля). Нет — вернёт −1
s.Remove(pos, n)удаляет n символов начиная с позиции pos
s.PadLeft(n)выравнивает по правому краю, добавляя пробелы слева до длины n
s.PadRight(n)то же, но пробелы справа

PadLeft на примере

Хочешь вывести числа в столбик:

text5
100
-20

Без PadLeft — криво. С PadLeft(6) — красиво:

text     5
   100
   -20
csharpdouble x = 5;
string s = Convert.ToString(x);   // "5"
s = s.PadLeft(6);                 // "     5"
Console.WriteLine(s);

Зачем Convert.ToString

PadLeft работает только со строками. Число double сначала надо превратить в string — для этого Convert.ToString.

8Math — математика

Класс Math содержит все нужные функции. В нём всё статическое — не нужно создавать объект, просто вызывай Math.что-то.

МетодЧто делает
Math.Sqrt(x)квадратный корень
Math.Pow(x, y)x в степени y
Math.Abs(x)модуль (убирает минус)
Math.Round(x, n)округляет до n знаков
Math.Min(a, b), Math.Max(a, b)минимум / максимум

Пример: формула Герона

Площадь треугольника со сторонами a, b, c:

S = √(p·(p-a)·(p-b)·(p-c)), где p = (a+b+c)/2 — полупериметр.

Сторона по координатам (x1,y1) и (x2,y2): a = √((x2-x1)² + (y2-y1)²).

csharpdouble a = Math.Sqrt(Math.Pow(x2 - x1, 2) + Math.Pow(y2 - y1, 2));
double p = (a + b + c) / 2.0;
double S = Math.Sqrt(p * (p - a) * (p - b) * (p - c));
Console.WriteLine("S = " + S);

9Примеры задач — коротко

Таблица температур (while)

csharpdouble lower = -20, upper = 100, step = 10;
double k = 9.0 / 5.0;
double c = lower;
while (c <= upper)
{
    double f = k * c + 32;
    string cs = Convert.ToString(c).PadLeft(4);
    string fs = Convert.ToString(f).PadLeft(6);
    Console.WriteLine(cs + " °C   " + fs + " °F");
    c += step;
}

Что важно: 9.0/5.0, а не 9/5! Если написать 9/5, это деление целых → результат 1, а не 1.8.

Таблица температур (for)

csharpfor (double f = 0; f <= 451; f += 50)
{
    double c = (f - 32) * 5.0 / 9.0;
    Console.WriteLine(f.ToString("F1").PadLeft(6) + " °F   " + c.ToString("F1") + " °C");
}

Масса газа (задача 1.2.3)

csharpConsole.Write("Давление (ати): ");
double p = Convert.ToDouble(Console.ReadLine());
Console.Write("Температура (°C): ");
double T = Convert.ToDouble(Console.ReadLine());
double R = 287, V = 1.0;
double m = (p + 1) * 98000 * V / (R * (T + 273));
Console.WriteLine($"Масса: {m:F2} кг");
💡

$"...{m:F2}..." — интерполяция строк. Проще, чем "...{0:F2}...", m. Работает с C# 6+. Если VS старый — используй m.ToString("F2").

10Вопросы на защите

Что такое точка входа в программу?

Метод Main. С него .NET начинает выполнение. Без него программа не запустится. Обычно static void Main(string[] args) — args это аргументы из командной строки (можно убрать для простоты).

Зачем using System в начале?

Чтобы писать Console.WriteLine, а не System.Console.WriteLine. Директива просто сокращает запись — «разреши пользоваться классами из System без полного имени».

Что такое namespace?

«Фамилия» проекта. Нужна, чтобы классы из разных сборок не конфликтовали по именам. У тебя namespace — это имя твоего проекта (lab1_1).

Чем Write отличается от WriteLine?

WriteLine после вывода переходит на новую строку. Write — нет, следующий вывод продолжит с той же строки.

Почему ReadLine возвращает string, а не число?

Потому что пользователь может ввести что угодно. Console не знает, число там или слово. Чтобы превратить в число — используй Convert.ToInt32 / ToDouble.

Чем F5 отличается от Ctrl+F5?

F5 — запуск с отладчиком (можно ставить точки останова). Ctrl+F5 — без отладчика, быстрее, для простой проверки.

Что делает PadLeft?

Добавляет пробелы слева до нужной длины. Используется для выравнивания столбцов таблицы по правому краю. Пример: "5".PadLeft(4) → " 5".

Почему 9.0/5.0, а не 9/5?

Потому что 9/5 — деление целых, результат будет 1 (целочисленное деление отбрасывает дробь). А 9.0/5.0 — деление double, результат 1.8.

Что делает Math.Sqrt? Math.Pow?

Math.Sqrt(x) — корень квадратный из x. Math.Pow(x, y) — x в степени y. Обе — из класса Math, писать Math. обязательно.

Чем int отличается от double?

int — только целые числа (32 бита). double — дробные числа, 15–16 значащих цифр. Для температуры, площади, массы — double; для возраста, счётчиков — int.

Где лежит готовый .exe?

В папке проекта: bin/Debug/Имя.exe. Появляется после сборки (F6 или F5).

Зачем Console.ReadLine() в конце программы?

Чтобы окно консоли не закрылось сразу после вывода. Программа «ждёт» нажатия Enter — ты успеваешь прочитать результат.
