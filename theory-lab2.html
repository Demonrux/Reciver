1Классы и объекты — что это

Класс — это чертёж. Объект — это вещь, сделанная по чертежу.

Класс

Чертёж автомобиля. На бумаге — какая форма, сколько колёс, что где. Но это не машина, на ней нельзя ездить.

Объект

Конкретная машина, сделанная по чертежу. Их можно сделать много: красная, синяя — все по одному чертежу.

csharpclass Car                     // ← ЧЕРТЁЖ
{
    public string Color;         // что у машины есть
    public void Go() { Console.WriteLine("Врум!"); }  // что умеет
}

// Использование:
Car myCar = new Car();   // ← ОБЪЕКТ (построили машину)
myCar.Color = "red";
myCar.Go();                // Врум!

Что есть у класса

НазваниеЧто этоАналогия
Поле (member data)переменная внутри классацвет машины
Метод (member function)функция внутри класса«поехали»
Конструкторфункция, которая вызывается при newсборка машины на заводе

Зачем разбивать на классы

Программа из одного метода Main на 200 строк — это кошмар. Легче читать, если каждый класс отвечает за одну задачу:

  • Класс Gaz — знает всё про газ (расчёт массы);
  • Класс Program — знает, как запустить и что ввести.

Это называется разделение ответственности.

2Конструкторы и перегрузка

Конструктор — это специальный метод, который автоматически вызывается при создании объекта через new. Имя конструктора = имя класса.

csharpclass DialogClass
{
    public string strX, strY;

    // Конструктор 1 — без параметров («по умолчанию»)
    public DialogClass() { Console.WriteLine("Создан пустой"); }

    // Конструктор 2 — с параметрами
    public DialogClass(string x, string y)
    {
        strX = x;  strY = y;
        Console.WriteLine("Создан с параметрами");
    }
}
csharpDialogClass d1 = new DialogClass();              // вызовется конструктор 1
DialogClass d2 = new DialogClass("John", "Никита");   // вызовется конструктор 2

Что такое «перегрузка» (overload)

Это когда у двух методов одно имя, но разные параметры. Компилятор сам решает, какой вызвать — по типу и количеству аргументов.

✓

В примере SayHi() и SayHi(string s) — перегрузка. Вызываешь d1.SayHi() — без параметров. Вызываешь d2.SayHi("John") — с параметром. C# разберётся.

Зачем два конструктора

  • Иногда нужно создать «пустой» объект — заполнить поля позже.
  • Иногда удобно сразу передать значения.
  • Оба варианта сосуществуют благодаря перегрузке.

3public и private — кто что видит

Каждое поле и метод в классе имеет уровень доступа: кто может к нему обращаться.

Ключевое словоКто видит
publicвсе — можно из любого места программы
privateтолько внутри своего класса (по умолчанию, если не указано)
csharpclass Car
{
    public string Color;      // снаружи можно: myCar.Color = "red";
    private int enginePower;   // снаружи НЕЛЬЗЯ: myCar.enginePower — ошибка
}
⚠

Правило хорошего тона: поля обычно делают private, а доступ к ним дают через свойства или методы. Но в лабе поля public — так требует задание, для простоты.

Зачем вообще private: чтобы программист случайно не сломал внутреннее состояние объекта. Класс сам решает, что показывать наружу, а что прятать.

4Форматирование строк — {0}, {1}

В C# есть очень удобный способ собрать строку из кусочков:

csharpint age = 25;
string name = "Иван";
Console.WriteLine("Меня зовут {0}, мне {1} лет", name, age);

Выведет: Меня зовут Иван, мне 25 лет

Как работает:

  • {0} — вместо него подставляется первый аргумент после строки (name);
  • {1} — второй аргумент (age);
  • и так далее.

Число в скобках — это номер аргумента, начиная с 0.

💡

Одно и то же можно делать через +: "Меня зовут " + name + ", мне " + age + " лет". Но с {0} код читаемее, особенно если подстановок много.

Подстановка в любой порядок

csharpConsole.WriteLine("{1} моложе, чем {0}", 40, 20);
// → "20 моложе, чем 40"

Аргументы идут по порядку, а подставляются по номеру в фигурных скобках.

Массив в качестве аргументов

csharpobject[] data = { "Привет", 20.9, 1, "ABCD" };
Console.WriteLine("{0}, {1}, {3}", data);
// → "Привет, 20.9, ABCD"

Если вместо отдельного аргумента передать массив — номера в {} указывают на элементы массива.

5Спецификаторы формата — D, F, N, E, G

В фигурных скобках можно указать формат: {0:F2}, {0:D9} и т.д. После двоеточия — буква формата и сколько знаков.

СпецификаторЧто делаетПример
Dцелое с дополнением нулями слева"{0:D6}", 42 → 000042
Fфиксированная точность (сколько знаков после запятой)"{0:F2}", 3.14159 → 3.14
Eэкспоненциальный вид"{0:E4}", 12998.7 → 1.2999E+004
N«число» — с разделителями тысяч"{0:N2}", 1234567.89 → 1 234 567.89
Gобщий — сам решает F или E"{0:G3}", 1234.5 → 1.23E+03

Зачем N

N удобно для финансов: 1234567.89 → 1 234 567,89 (в русской локали). Пробелы между тысячами — читается легче.

Как выбрать

  • F — когда хочешь фиксированное количество знаков после запятой (масса, температура, деньги);
  • N — когда число большое и хочешь разделители тысяч;
  • D — для кодов, номеров, где важны нули впереди;
  • E — для очень больших / маленьких чисел;
  • G — если не знаешь, что лучше.
✓

Для лабы достаточно F (напр. {0:F2}). Всё остальное — знать, что существует.

6Работа с файлами — StreamWriter и StreamReader

Иногда вывод программы нужно сохранить в файл (например, чтобы открыть в Excel или распечатать). В C# для этого есть StreamWriter и StreamReader.

Порядок работы с файлом

  1. Подключить using System.IO; — там лежат классы для файлов.
  2. Открыть файл — создать переменную-«ручку».
  3. Писать / читать.
  4. Закрыть файл (обязательно!).

Запись в файл

csharpusing System.IO;

StreamWriter f = new StreamWriter("output.txt");   // открыли
f.WriteLine("Иван");                                  // пишем
f.WriteLine("25");
f.WriteLine("3.14");
f.Close();                                          // закрыли
⚠

Обязательно f.Close(). Если забыть — данные могут не сохраниться: они висят в буфере, пока не закроешь.

Чтение из файла

csharpStreamReader f = new StreamReader("output.txt");
string name = f.ReadLine();                       // "Иван"
int age    = Convert.ToInt32(f.ReadLine());  // 25 (строка → число)
double pi  = Convert.ToDouble(f.ReadLine()); // 3.14
f.Close();

Важно: ReadLine читает строку — даже если там число. Всегда нужно Convert, если нужен числовой тип.

Где лежит файл

По умолчанию — в папке рядом с .exe: bin/Debug/output.txt. Чтобы указать точный путь, пиши полностью: "D:\\C#\\input.txt" (двойные слэши — потому что \ в строке это escape-символ).

✗

Если файл не найден — программа упадёт с исключением. На ЛР №4 мы это ловим через try/catch. На ЛР №2 достаточно того, что файл точно существует.

7Массивы — 1D и 2D

Массив — это коробка с ячейками, где каждая ячейка хранит одно значение, и у каждой есть номер (индекс).

Одномерный массив (список)

csharpint[] numbers = new int[5];     // 5 ячеек: 0, 1, 2, 3, 4
numbers[0] = 100;
numbers[4] = 200;
// numbers[5] — ошибка! Индексация с нуля!
⚠

Индексация в C# начинается с 0. Если массив на 5 элементов, индексы: 0, 1, 2, 3, 4. Не 1..5. Это классическая ловушка на защите.

Двумерный массив (таблица)

csharpint[,] matrix = new int[6, 6];     // 6 строк × 6 столбцов
matrix[0, 0] = 5;
matrix[5, 5] = 5;

Заполнение и вывод

csharp// Заполнили все ячейки значением 5
for (int i = 0; i < 6; i++)
    for (int j = 0; j < 6; j++)
        matrix[i, j] = 5;

// Вывели на экран
for (int i = 0; i < 6; i++)
{
    for (int j = 0; j < 6; j++)
        Console.Write(matrix[i, j] + " ");
    Console.WriteLine();       // переход на новую строку
}

Внутренний цикл выводит одну строку матрицы, внешний после каждой строки делает WriteLine() — чтобы следующая строка была ниже.

Значения по умолчанию

При создании массива все ячейки получают значение по умолчанию:

  • int, double → 0;
  • bool → false;
  • string → null.

8Методы System.Array

В C# любой массив наследует от класса System.Array — у него есть готовые полезные методы. Не надо писать вручную.

Метод / свойствоЧто делает
arr.Lengthобщее количество элементов
arr.GetLength(0)размер по первому измерению (для 2D)
arr.GetLength(1)размер по второму измерению
Array.Clear(arr, 0, arr.Length)обнулить диапазон элементов
Array.IndexOf(arr, x)найти первое вхождение x
Array.Reverse(arr)развернуть массив
Array.CopyTo(...)скопировать в другой массив
arr.GetValue(i) / arr.SetValue(x, i)получить / установить значение по индексу

Контроль границ — важное

Если выйти за пределы массива — C# кинет IndexOutOfRangeException. Это не баг, а защита: программа упадёт сразу, а не будет молча читать мусор.

✓

Это плюс C# перед C/C++: там выход за границы не ловится и приводит к непредсказуемому поведению. В C# — сразу ошибка.

9Switch-case — выбор по числу

Когда вариантов много (не 2, а 3-5), удобнее не писать длинную цепочку if/else if, а использовать switch.

csharpint n = Convert.ToInt32(Console.ReadLine());

switch (n)
{
    case 1:
        R = 287;  gaz = "воздух";
        break;

    case 2:
        R = 297;  gaz = "азот";
        break;

    default:                          // сюда, если ничего не подошло
        R = 287;  gaz = "воздух (по умолчанию)";
        Console.WriteLine("Неверный выбор, считаю для воздуха");
        break;
}

Ключевые слова

  • switch (x) — «сравни x с вариантами ниже»;
  • case 1: — если x == 1, выполнить этот блок;
  • break — выход из switch. Без него выполнение «провалится» в следующий case (иногда это нужно, но чаще — баг);
  • default — если ни один case не подошёл (аналог else).

Switch vs if-else

switch удобнее, когда вариантов много и они проверяют равенство. Для сложных условий (x > 5 && x < 10) — if/else.

10Класс Gaz — пример из лабы

По заданию 2.2.1 нужно переделать задачу про газ из ЛР №1 в класс Gaz. Вот типичная структура:

csharpclass Gaz
{
    // Константы газовых постоянных
    public const float R_Vozd = 287;
    public const float R_Azot = 297;

    // Поля
    public float V, R;
    public double p, T, m;
    public string GazName;

    // Конструктор — принимает номер газа
    public Gaz(int n)
    {
        switch (n)
        {
            case 1: R = R_Vozd; GazName = "воздух"; break;
            case 2: R = R_Azot; GazName = "азот";   break;
            default: R = R_Vozd; GazName = "воздух (по умолч.)";
                     Console.WriteLine("Неверный выбор"); break;
        }
    }

    // Методы
    public void Set_V() { Console.Write("Объём: "); V = (float)Convert.ToDouble(Console.ReadLine()); }
    public void Set_P() { Console.Write("Давление: "); p = Convert.ToDouble(Console.ReadLine()); }
    public void Set_T() { Console.Write("Температура: "); T = Convert.ToDouble(Console.ReadLine()); }

    public void Calc()
    {
        m = (p + 1) * 98000 * V / (R * (T + 273));
    }

    public void Show()
    {
        Console.WriteLine($"Газ: {GazName}, масса: {m:F2} кг");
    }
}

// Использование в Main:
Console.Write("Выберите газ (1-воздух, 2-азот): ");
int n = Convert.ToInt32(Console.ReadLine());

Gaz g = new Gaz(n);
g.Set_V();  g.Set_P();  g.Set_T();
g.Calc();
g.Show();
✓

Разделение ответственности: класс Gaz знает про газ, класс Program — про запуск. Каждый занимается своим делом.

Зачем конструктор принимает номер газа

Потому что R и GazName зависят от выбора — их логично задать сразу при создании. Пользователь ввёл 1 — объект создан для воздуха; ввёл 2 — для азота.

11Вопросы на защите

Что такое класс и объект?

Класс — чертёж (описание полей и методов). Объект — конкретная «вещь», созданная по этому чертежу через new. Один класс — много объектов.

Что такое конструктор?

Специальный метод, который автоматически вызывается при создании объекта. Имя = имя класса. Может принимать параметры. Если не написать ни одного — C# создаст конструктор по умолчанию сам.

Что такое перегрузка?

Несколько методов с одним именем, но разными параметрами. Компилятор сам выбирает нужный по типу и количеству аргументов. Пример: SayHi() и SayHi(string).

Чем public отличается от private?

public — видно отовсюду. private — только внутри своего класса. По умолчанию все члены класса — private.

Что означает {0} в строке формата?

«Подставь сюда первый аргумент после строки». {1} — второй. Номера начинаются с 0. Пример: "{0} и {1}", "a", "b" → a и b.

Что делает F2 в {0:F2}?

Формат F — фиксированная точность. 2 — два знака после запятой. Пример: "{0:F2}", 3.14159 → 3.14.

Чем N отличается от F?

F — просто фиксированное количество знаков после запятой. N — то же, но с разделителями тысяч. Пример: N2 для 1234567.89 → 1 234 567,89.

Зачем using System.IO?

Чтобы пользоваться классами StreamWriter, StreamReader, File и др. — они лежат в пространстве имён System.IO.

Зачем f.Close() в конце?

Без него данные могут не сохраниться: они висят в буфере. Close() «сбрасывает» буфер на диск и освобождает файл для других программ.

С какого индекса начинается массив?

С 0. Массив на 5 элементов имеет индексы 0, 1, 2, 3, 4. Обращение к arr[5] — ошибка IndexOutOfRangeException.

Чем отличается arr.Length от arr.GetLength(0)?

Length — общее количество элементов (для 1D — размер). GetLength(0) — размер по первому измерению (для 2D — строки). GetLength(1) — столбцы.

Зачем break в switch?

«Выйти из switch». Без него выполнение провалится в следующий case — иногда это нужно (fall-through), но чаще это баг.

Что такое default в switch?

Блок, который выполняется, если ни один case не подошёл. Аналог else.

Почему в классе Gaz константы — const?

const — константа, значение которой нельзя изменить. Газовые постоянные (R_Vozd = 287) не меняются — логично объявить их const, чтобы случайно не перезаписать.

Почему R, V, p, T — public?

По заданию лабы их нужно читать и менять из Main. Если бы они были private, программа не скомпилировалась бы: «недоступно из-за уровня защиты».

12Умные фразы для защиты

1

«Класс — это абстракция: описание того, что будет общего у всех объектов. Конкретные объекты создаются через new и живут своей жизнью».

2

«Мы используем перегрузку конструкторов: можно создать объект как с параметрами, так и без — компилятор сам выберет по аргументам».

3

«Разделение на классы — это принцип единственной ответственности: Gaz отвечает за расчёт газа, Program — за запуск. Так код легче тестировать и переиспользовать».

4

«StreamWriter буферизует запись — поэтому обязателен Close, иначе данные останутся в памяти и не попадут в файл».
